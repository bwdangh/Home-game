# Home Game Ledger

A private, host-only poker home game tracker for iPhone. It covers game nights, seats, buy-ins, rebuys, cash-outs, settle-at-end balances, rake, tips, expenses and reports.

Open the GitHub Pages address in Safari and tap **Share → Add to Home Screen**. All records stay on the phone in the browser's storage, behind a 6-digit passcode. Nothing is sent to a server.
